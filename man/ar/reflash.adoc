== Name

reflash - إعادة كتابة بيانات الجهاز أو الملف في مكانها (مساج SD)

== Synopsis

*reflash* [_خيار_]... [_DEVICE/FILE_]

== Description

*reflash* يعيد كتابة جهاز كتلي أو ملف عادي *في مكانه* حتى لا يفقد الوسيط الومضي غير المستخدم شحنته ويتلف البيانات. تُقرأ كل وحدة إدخال/إخراج وتُكتب كما هي. التقدم والسرعة والوقت المتبقي تذهب إلى stderr. تتوفر واجهة wxWidgets مع *--gui* عند وجود شاشة؛ مع *--gui* يمكن حذف _DEVICE/FILE_ وفتحه من قائمة File.

يُدعم وضعان:

* *linear* (الافتراضي) -- عامل الهدف كنطاق بايت خام. إن وُجد جدول أقسام، يُعاد كتابة الجدول وكل قسم على حدة.
* *recursive* -- يتجول في نظام ملفات غير مُعلّق (FAT/exFAT، NTFS، ext2/3/4) عبر بنى القرص (وليس VFS معلّق) ويعيد كتابة بيانات الملفات والبيانات الوصفية الأساسية.

تسجّل قاعدة SQLite المسارات وSHA-1 وعدادات المساج/التحقق والمناطق التالفة. تستخدم جداول الأقسام وبيانات نظام الملفات الوصفية مسارات خاصة مثل `::mbr` و`::gpt` و`::part-N` و`::boot` و`::superblock`.

تعمل إعادة الكتابة دائماً على جهاز *غير معلّق* وتمس فقط البيانات المخصصة (يُتخطى الفراغ). بيانات NTFS المضغوطة أو المشفّرة تُعاد كتابتها كما على القرص (بلا فك تشفير). تُحسب SHA-1 *بعد* إعادة الكتابة ونظام الملفات معلّق (القراءة وحدها تكفي). تُفك التعليقات الحالية ثم تُستعاد (بما فيها القراءة/الكتابة). تُحسب SHA-1 عند استخدام قاعدة بيانات: دائماً بلا واجهة، وفي الواجهة فقط بعد Database → Open. لا تسأل الواجهة على الطرفية. الملف العادي أو loop يُعلّق للقراءة فقط عبر FUSE. القرص الحقيقي يستخدم udisks ثم `sudo`/`pkexec`. (*fakeroot* لا يمنح `CAP_SYS_ADMIN` ولا يفيد.) Edit → Dry-run يقرأ المسح ولا يكتب.

تُفتح الملفات العادية للقراءة/الكتابة دون اقتطاع.

== الخيارات

*-b, --block-size* _NUM_::
  حجم كتلة الإدخال/الإخراج بالبايت. الافتراضي: تلقائي (`BLKSSZGET`، أو `st_blksize` للملف، أو 4096).

*-d, --sqlite-db* _FILE_::
  قاعدة إدارة SQLite. الافتراضي: `~/.cache/reflash/<name>.sqlite`.

*-t, --test*::
  تحقق مقابل القاعدة (قراءة + SHA-1)؛ بلا إعادة كتابة. دائماً بلا واجهة.

*-l, --linear*::
  إعادة كتابة خام للجهاز/الملف (الافتراضي).

*-r, --recursive*::
  تجول في نظام الملفات وإعادة الكتابة. تُفك التعليقات ذات الصلة أولاً ثم تُستعاد.

*-g, --gui*::
  افتح نافذة wxWidgets (يتطلب `DISPLAY` أو Wayland). _DEVICE/FILE_ اختياري؛ File → Open / Device ثم Start.

*-v, --verbose*::
  زيادة السجلات.

*-q, --quiet*::
  تقليل السجلات.

*-h, --help*::
  اعرض المساعدة واخرج.

*--version*::
  اعرض الإصدار واخرج.

== حالة الخروج

*0*:: نجاح (قد تُسجَّل أخطاء إدخال/إخراج لمناطق فردية في القاعدة).
*1*:: فشل.
*2*:: خطأ في الاستخدام.

== ملاحظات

تحتاج أجهزة الكتل عادةً إلى root. تُفك التعليقات ذات الصلة لإعادة الكتابة ثم تُستعاد. تُحسب SHA-1 على محتوى الملفات المعلّقة بعد إعادة الكتابة. لا تُعاد كتابة الفراغ/غير المخصص. بعد التشغيل يمكن تصدير المناطق التالفة كقائمة بأسلوب badblocks (توفّر الواجهة حوار حفظ). يمكن لملف SQLite واحد أن يحوي عدة أجهزة (`device` و`volume` و`object` و`folder` و`file`). يبقى SHA-1 المخزَّن صالحاً 183 يوماً ما لم تغيّر Preferences ذلك.
